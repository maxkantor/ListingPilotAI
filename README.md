# ListingPilot AI

**AI-powered marketing copilot for real estate agents.**

ListingPilot AI transforms raw property details into polished, platform-ready marketing content — MLS descriptions, social posts, and email blurbs — in seconds.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18, TypeScript, Vite, CSS Modules |
| Backend | ASP.NET Core Web API (.NET 8) |
| AI | OpenAI GPT-4o-mini (or built-in mock) |
| Routing | React Router v6 |
| Styling | CSS Modules + CSS Custom Properties |

---

## Getting Started

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- [Node.js 18+](https://nodejs.org/) and npm

---

### Backend

```bash
cd backend
dotnet run --project src/ListingPilot.Api
```

The API will start on `http://localhost:5000`.

**With OpenAI (optional):**

```bash
export OPENAI_API_KEY=sk-your-key-here
dotnet run --project src/ListingPilot.Api
```

Without an API key, the backend automatically uses the built-in mock service that generates realistic, property-specific content using string interpolation.

---

### Frontend

```bash
cd frontend
cp .env.example .env       # edit VITE_API_URL if needed
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/generate` | Generate marketing content for a property |
| `GET` | `/api/sample-property` | Returns a pre-filled sample property (Tucker, GA) |
| `GET` | `/api/history` | List previously generated entries |
| `POST` | `/api/history` | Save a history entry |

---

## Environment Variables

### Frontend (`frontend/.env`)

| Variable | Default | Description |
|---|---|---|
| `VITE_API_URL` | `http://localhost:5000` | Base URL of the backend API |

### Backend

| Variable | Description |
|---|---|
| `OPENAI_API_KEY` | OpenAI API key. If absent, mock AI service is used automatically. |

Alternatively, set `OpenAI:ApiKey` in `appsettings.Development.json`.

## Generated Output Types

1. **MLS Description** — Standard property listing description
2. **Luxury Description** — Elevated, premium-tone narrative
3. **Facebook Post** — Engaging post with CTA and hashtags
4. **Instagram Caption** — Social-friendly copy with relevant hashtags
5. **LinkedIn Post** — Professional market insight angle
6. **Email Blurb** — Concise newsletter / drip email copy
